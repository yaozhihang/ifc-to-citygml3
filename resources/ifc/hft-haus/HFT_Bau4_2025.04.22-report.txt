2. Conclusion
-------------

The Java converter produces correct output with no data loss. All discrepancies
have known root causes:

  (a) 2 missing elements (1 slab, 1 roof): geometry not available in the
      pre-extracted .geom.json file (Python/IfcOpenShell extraction issue).

  (b) 123 unmapped doors/windows: IFC model lacks IfcRelFillsElement
      relationships for these elements (Revit IFC export deficiency).
      Recoverable with --unrelated-doors-and-windows-in-dummy-bce flag.

  (c) IfcStair, IfcGeographicElement, IfcOpeningElement: intentionally not
      mapped to CityGML (by design).
